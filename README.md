# QalaLine Connect

Жоғары деңгейде жаса: QalaLine — Ақтау қаласының тұрғындарына қалалық инфрақұрылымдағы мәселелерді фото және геолокация арқылы хабарлап, олардың шешілу барысын бақылауға мүмкіндік беретін цифрлық кері байланыс платформасы. Платформа арнайы Ақтау қаласына арналған (Ақтау қаласының картасы, микроаудандар/шағынаудандар бойынша мекенжай құрылымы, қалалық коммуналдық қызметтер мен әкімдік бөлімдері ескерілген). Барлық интерфейс таза қазақ тілінде (kk).

Карта бөлімін Ақтау қаласының аудандары мен негізгі көшелеріне бейімдеп, өтініш маркерлерін санат және мәртебе бойынша көрсет.

Берілген HTML құрылымы толық негіз ретінде қолданылуы керек:
1. Басты бет:
- Hero бөлім: Ақтау қаласына арналған тақырып ("QalaLine — Ақтау қаласының мәселесін хабарлаңыз"), сипаттама, жылдам әрекет батырмалары (Өтініш жіберу, Өтінішті бақылау, Ақтау картасы).
- "QalaLine қалай жұмыс істейді?" (6 қадам: 1. Фото жіберіңіз, 2. AI тексереді, 3. Геолокация, 4. Қызметкерге жіберіледі, 5. Бақылаңыз, 6. WhatsApp хабарламасы).
- "Қандай мәселелерді жіберуге болады?" (Жол тесігі, Ашық люк, Көше жарығы, Аялдама, Қоқыс, Жол белгілері, Су/кәріз, Аула абаттандыру).

2. Өтініш жіберу формасы:
- Аты-жөніңіз
- Телефон / WhatsApp нөмірі (+7 форматында)
- Ақтаудағы орны: шағынаудан (микрорайон: 1-ден 35-ке дейін және жаңа шағынаудандар), үй/ғимарат немесе көше
- Мәселе санаты (Жол тесігі, Ашық люк, Көше жарығы, Аялдама, Қоқыс, Жол белгісі, Су/кәріз, Басқа)
- Мәселенің сипаттамасы
- Фото жүктеу және алдын ала қарау (preview)
- AI тексеруі: жүктелген фотоның қалалық мәселе екенін және қайталанбағанын алдын ала тексереді
- Геолокация: ағымдағы GPS нүктені анықтау немесе Ақтау картасынан таңдау
- Жібергенде автоматты түрде жеке бақылау коды беріледі (мысалы, #AKT-2026-XXXX)

3. Өтінішті бақылау:
- Өтініш нөмірімен жылдам іздеу
- Мәртебе кезеңдері: Жаңа (сары), Қаралуда / Жұмыста (көк), Орындалды (жасыл), Қабылданбады (қызыл)
- Толық ақпарат: күні, шағынауданы, мәселе санаты, фото және жауапты маман пікірі

4. Ақтау қаласының интерактивті картасы:
- Ақтау қаласының картасына (Каспий жағалауы, 1-35 шағынаудандар, басты көшелер мен даңғылдар: Тәуелсіздік, Н. Назарбаев/Орталық, т.б.) бейімделген
- Сүзгілер: санат бойынша (барлығы, жол, люк, жарық, қоқыс және т.б.) және мәртебе бойынша (барлығы, 🔴 жаңа, 🟡 жұмыста, 🟢 орындалды)
- Әр маркерді басқанда шағынаудан, мәселе санаты, фотосы, мәртебесі көрсетілетін карточка

5. Қызметкерлер / Әкімдік бөлімі:
- Кіру: admin / 1234
- Статистика дашборды: Барлық өтініштер, Жаңа, Жұмыста, Орындалды
- Өтініштер тізімі мен сүзгілер
- Мәртебені өзгерту, шешілген фотоны тіркеу, түсініктеме жазу
- Тұрғынның нөміріне WhatsApp арқылы тікелей хабарлама жіберу батырмасы (wa.me сілтемесімен дайын хабарлама мәтіні)

6. Заманауи, ыңғайлы, мобильді телефондарға толық бейімделген (responsive) және эстетикалық таза дизайн. Деректерді Lovable Cloud арқылы сақтау. Бастапқы демонстрациялық Ақтау мәліметтері (бірнеше шағынаудандағы нақты нүктелермен) қосылсын.
